# Sistemas externos

Registo das ferramentas onde os sistemas do catálogo também estão inventariados (GLPI, Zabbix, ServiceNow), cada uma identificada por uma cor.

```{video} 353-integracoes
```

O vídeo apresenta as quatro integrações: sistemas externos, MISP, feeds RSS e diretório.

## Acesso

**Governar** > **Administração do sistema** > **Integrações** > **Sistemas Externos**

```{figure} /_static/capturas/adm-sistemas-externos/menu.jpg
:alt: Menu lateral: Governar > Administração do sistema > Integrações > Sistemas Externos

Caminho de acesso no menu lateral. Os números indicam a ordem dos cliques.
```

## Configuração do ecrã

```{figure} /_static/capturas/adm-sistemas-externos/lista-1.jpg
:alt: A lista de sistemas externos e o formulário para acrescentar

A lista de sistemas externos e o formulário de adição.
```

No ecrã, encontra os seguintes elementos:

1. **Nome:** Nome da ferramenta externa.
2. **Cor:** Cor que identifica a ferramenta no catálogo de segurança.
3. Botão **Adicionar:** Regista a ferramenta.

**Como adicionar:** Indique o **nome** e a **cor** da ferramenta e clique em **Adicionar**. A cor identifica as ligações no catálogo de segurança: um sistema registado no GLPI e no Zabbix apresenta as duas cores.

## Resumo

- Regista as ferramentas externas onde os sistemas também estão inventariados.
- A cor de cada ferramenta é apresentada no catálogo de segurança.
- Ver também {doc}`/platform/inventory/security-catalogue`.
