# Módulo C — A plataforma, passo a passo

A plataforma ecrã a ecrã, **pela ordem dos menus**, que corresponde à ordem de execução do
trabalho: do primeiro acesso à visita de certificação. Cada página segue a mesma estrutura:

1. conceito;
2. obrigação a que responde;
3. **informação a solicitar** e respetivos responsáveis na organização;
4. ecrã, campo a campo;
5. funcionalidades da plataforma;
6. limitações.

## Como ler as capturas de ecrã

Cada página começa pela secção **Acesso**: o caminho no menu lateral, com cada nível numerado pela
ordem dos cliques.

Nas capturas, os números correspondem à lista apresentada por baixo de cada imagem:

- **números a azul**: elementos a consultar ou a preencher no ecrã;
- **números a laranja**: locais onde se clica ou se escreve, pela ordem de execução.

```{note}
As capturas foram obtidas no **ambiente de testes** (identificado pela faixa amarela «AMBIENTE DE
TESTES»), com a organização fictícia utilizada em toda a formação: o Instituto Politécnico de Vila
Nova. Todos os nomes e dados são fictícios. Ver {doc}`/installation/test-environment`.
```
