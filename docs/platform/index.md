# Módulo C — A plataforma, passo a passo

A plataforma ecrã a ecrã, **pela ordem dos menus**, que é a ordem em que o trabalho se faz: do
primeiro acesso à visita de certificação. Cada página segue as mesmas seis partes:

1. o conceito;
2. a obrigação que serve;
3. **o que pedir a quem** dentro da organização;
4. o ecrã, campo a campo;
5. o que a plataforma faz com isso;
6. o que não faz.

## Como ler as capturas de ecrã

Cada página abre com **Onde fica no menu**: o caminho no menu lateral, com cada nível numerado
pela ordem em que se abre.

Nas capturas, os números desenhados correspondem à lista por baixo de cada imagem:

- **números a azul**: o que se deve ver ou preencher nesse ecrã;
- **números a laranja**: onde se clica ou se escreve, pela ordem em que se faz.

```{note}
As capturas são do **ambiente de testes** (daí a faixa amarela «AMBIENTE DE TESTES»), com a
organização fictícia de toda a formação: o Instituto Politécnico de Vila Nova. Todos os nomes e
dados são inventados. Ver {doc}`/installation/test-environment`.
```
