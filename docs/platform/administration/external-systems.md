# Sistemas externos

As ferramentas onde os sistemas do catálogo também estão registados (GLPI, Zabbix, ServiceNow), cada uma com a sua cor.

```{video} 353-integracoes
```

O vídeo mostra as quatro integrações: os sistemas externos, o MISP, os feeds RSS e o diretório.

## Onde fica no menu

**Menu:** Governar › Administração do sistema › Integrações › Sistemas Externos

```{figure} /_static/capturas/adm-sistemas-externos/menu.jpg
:alt: Menu lateral: Governar › Administração do sistema › Integrações › Sistemas Externos

O caminho no menu lateral: Governar › Administração do sistema › Integrações › Sistemas Externos.
```

1. No menu lateral, abra **Governar**.
2. Dentro dele, abra **Administração do sistema**.
3. Dentro dele, abra **Integrações**.
4. Clique em **Sistemas Externos**: abre o ecrã desta página.


## O ecrã

```{figure} /_static/capturas/adm-sistemas-externos/lista-1.jpg
:alt: A lista de sistemas externos e o formulário para acrescentar

A lista de sistemas externos e o formulário para acrescentar.
```

1. **Nome**
2. **Cor**
3. **Adicionar**


Dê um **nome** e uma **cor** a cada ferramenta e clique em **Adicionar**. A cor é a que depois distingue as ligações no catálogo de segurança: um sistema identificado no GLPI e no Zabbix mostra as duas, cada uma com a sua cor.

## Resumo

- Regista as ferramentas externas onde os sistemas também existem.
- A cor de cada uma aparece no catálogo de segurança.
- Ver também {doc}`/platform/inventory/security-catalogue`.
